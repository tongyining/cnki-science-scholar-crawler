# 🔍 AI-Assisted Literature Collector (AI学术文献采集助手)

[![GitHub stars](https://img.shields.io/github/stars/tongyining/cnki-science-scholar-crawler)]()
[![GitHub license](https://img.shields.io/github/license/tongyining/cnki-science-scholar-crawler)]()

**AI-Assisted Literature Collector** 是一个专为研究生和科研人员设计的浏览器插件，用于解决文献综述阶段海量文献检索效率低下的问题。它能根据AI生成的关键词，从 **CNKI (知网)** 和 **Science** 等主流学术数据库中，**自动抓取成百上千篇**相关文献，帮助你将文献调研时间从数小时缩短至十几分钟，是撰写毕业论文和学术论文的强大辅助工具。

![插件界面截图](/images/plugin-screenshot.png)

## 文献智能采集助手

本插件专为论文写作设计，能够快速、批量采集指定领域的学术文献（如知网、Science 等），并通过 AI 辅助分析与整理。

> 传统手动搜索一个领域少则几百篇、多则上千篇文献，效率极低。  
> 使用本插件，**几分钟到十几分钟**即可获取成百上千篇文献，大幅提升文献调研效率。

## 📖 使用教程

### 第一步：下载插件

1. 点击 GitHub 页面右上角的 **Code** 按钮。
2. 选择 **Download ZIP**。
3. 将压缩包解压到一个自己熟悉的文件夹。

![下载ZIP截图](/images/download-zip.png)

### 第二步：导入与安装插件

1. 使用 Chrome 或 360 浏览器，进入扩展程序管理页面（地址栏输入 `chrome://extensions/`）。
2. **开启右上角的“开发者模式”**。

   ![开发者模式截图](/images/developer-mode.png)

3. 点击左上角 **“加载已解压的扩展程序”**，选择刚才解压的文件夹。
4. 插件安装完成后，在浏览器右上角点击拼图图标，找到本插件，点击后面的 **固定** 按钮，将其固定到工具栏。

   ![固定插件截图](/images/pin-plugin.png)

5. 点击插件图标，即可显示采集主界面。

   ![主界面截图](/images/plugin-screenshot.png)

### 第三步：生成关键词

让 AI（如 ChatGPT、Claude 等）根据你的论文主题，生成一批**合适的检索关键词**。

> **关键词组合建议**  
> - 1 个关键词 → 搜索结果过多  
> - 3 个关键词 → 搜索结果过少  
> - **2 个关键词 → 最为理想**

如果需要用到英文文献，就让 AI 同时生成 **10 个中文关键词组合** + **10 个英文关键词组合**。

### 第四步：复制关键词并开始采集

1. 将 AI 生成的关键词（**一行一个**）复制到插件的搜索框中。
2. 点击 **「开始采集」** 按钮。

### 第五步：等待采集完成

- 采集速度约为 **1 分钟处理 5–10 个关键词**（一行一个）。
- 采集的时候只会翻页5次（如果要采集更多文献，就需要设置每页显示更多文献数量）。
- 采集完成后，插件会弹出提示。

### 第六步：查看与导出结果

1. 点击 **「查看批次」**。
2. 点击 **「全屏」** 按钮，会在新标签页中打开采集结果。

> **Science 数据库特殊操作**  
> 由于 Science 网站频繁出现验证，无法自动采集。请手动将关键词一个个复制过去搜索，然后点击插件图标，将采集源切换到 **Science**，再点击 **「采集当前页数据」**。

⚠️ **批次管理**  
- 可以点击 **「新建批次」** 创建新的采集任务。  
- 也可以选择保存到 **最新的一个批次**。  
- 若需重新采集或同时撰写多篇论文，建议新建批次。

   ![批次管理截图](/images/batch-manager.png)

## 📌 导出注意事项

- **自动导出的 CSV 文件** 格式存在特殊处理（为兼容 Excel 计算，避免科学计数法等问题），**不推荐直接使用**。
- **推荐做法**：在全屏查看结果界面，**手动复制**所需内容到本地文件中，格式最稳定。
